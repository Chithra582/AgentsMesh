# Autopilot Agent Supervision Skill

Automates continuous steering of coding agents toward complex goals.

## Core Capabilities
- Detects pod terminal idle states and terminal completion signals.
- Generates context-aware follow-up instructions to overcome hurdles.
- Halts execution and triggers human takeover upon reaching iteration caps.
